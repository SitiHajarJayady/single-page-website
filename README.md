# single-page-website

A responsive single-page website developed to present key information about an organization and its upcoming event, including itinerary details, seating layout, and venue information.

## Overview

I started with a publicly available website template and customized it to meet the organization’s content and design needs. The final result is a clean, mobile-friendly site suitable for both desktop and mobile devices.

## Key Features

- **Template Customization**
  - Modified a web template to fit the organization's structure and branding
  - Reorganized sections to highlight the organization’s background, mission, and services

- **Event Information Section**
  - Added details their upcoming event, including:
    - Full itinerary/schedule
    - Venue map and seating layout for participant reference

- **Responsive Design**
  - Ensured compatibility across mobile and desktop devices
  - Used responsive layout techniques and media queries

- **JavaScript Enhancements**
  - Integrated a JavaScript image slider to display gallery or venue visuals
  - Enhanced user experience with interactive and lightweight design elements

## Contributions

- Researched and selected a suitable template
- Customized layout, structure, and content to fit organization and event needs
- Implemented mobile-responsive design across all sections
- Added image slider functionality using a JavaScript plugin
- Structured event-related content for clarity and usability
